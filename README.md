# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1icNB7cVSCIL9aQM9qGGaMi3oYMatOL23

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set up your `.env.local` file with required environment variables (see `.env.example`)
3. Run the app:
   `npm run dev`
